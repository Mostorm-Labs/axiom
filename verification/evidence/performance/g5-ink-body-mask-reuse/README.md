RSS sums this worker's processes and may count shared pages multiple times. It is neither unique physical RAM nor GPU memory. A larger quota is a ceiling, not an upfront allocation. The96MiB value is an engineering policy per Renderer, not a Skia/WebGL/hardware limit. Historically the shared quota was `maxBytes * 3` with32MiB cache (`6aa330a8`); `6407ab3b` separated optional capacity from shared admission. Current derived pixels, work surfaces, prepared data and pending GPU retirement compete for this quota. Canonical document/history, total WASM heap, other Renderers and driver/browser allocations are not all capped by it. Multiple documents/views can multiply resource use. The comparison supports testing desktop64/192 rather than merely doubling the hard cap. The source defaults remain unchanged; mobile and multiview policy require their own evidence.
