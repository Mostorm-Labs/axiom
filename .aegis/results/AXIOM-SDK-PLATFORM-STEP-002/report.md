# Windows adapter and Web owner — intermediate result

This is an intermediate implementation, not completion of the Windows/Web SDK task. Sources under test were dirty and are individually hashed in `manifest.json`; the commit containing this report pins those source bytes. Historical tests and C ABI/SDK locks were not changed.

Windows: the public Pimpl adapter borrows the public Composition and stages the existing D3D12 canonical/preview providers. It exposes bind, resize, loss/recovery, frame opportunity and present; the present path checks real provider Present counters before acknowledging the original Runtime work. Minimal Host now uses the adapter for surface setup, resize, positioning and frame opportunity/feedback. It still relies on private Runtime core for native input, IME, fonts and diagnostics; the old Runtime wrapper remains. The installed `Axiom::PlatformWindows` target was exercised by a fresh outside-repository Win32 app: actual HWND and D3D12 surfaces, synthetic Ink preview and Shape selection, facade identity, Present, resize, loss/recovery and close passed. The independently copied Skia SDK was verified against the lock; Semantic came from the locked SDK Store. This is not proof of physical scanout or physical input.

The owner/UI Windows configuration passed seven named CTests, including public adapter, real host adapter, four text entry/focus cases and Web surface test. A Debug UI OFF Windows build and adapter test passed. The separate initial REDs and real observations, including an incorrect initial assumption that Shape preview uses the Ink preview lane, are preserved in raw files. The latter sample was corrected to test an actual Ink preview followed by Shape creation; no product failure was relabelled.

WebSurfaceHost now holds a public Composition with its prior view ID and reuses its core through a transitional private port. Its native surface test and actual Chrome/WASM 44-assertion selection regression pass, and three existing installed C++ consumers pass. Web is not yet an independently installable SDK adapter and no mixed-stroke host/browser or physical tests are claimed. The known public input contact-reuse/generation ambiguity and D07 Protobuf/Abseil OOM remain open. Full Windows Host private-port/IME/resource closure, actual font sample, Web SDK, and deletion of the legacy Runtime wrapper remain unfinished. No Gate, release or physical PASS is claimed.
