# GT-G4-4 — Multi-Pointer Input & Gesture Arbitration

This package executes the two Notion authorities for G4.4 from the G4 functional
integration baseline. It is a normalized input/session substrate, not a new
semantic document model. Pointer identity, gesture claims, contact geometry,
preview state, and viewport state remain derived runtime state.

Work packages G4.4-00 through G4.4-10 execute continuously through automated
closure. Their terminal state is `READY_FOR_PHYSICAL_VERIFICATION`, not G4.4
PASS. Available Windows mouse and Android multitouch runs are capability-profile
evidence; they do not prove unavailable pen, pressure, palm, or Windows touch.

G4.4-11 owns the unified physical qualification and final Gate closure. Pen and
pressure scenarios apply only when the qualification device exposes those
capabilities. Synthetic replay remains automated correctness evidence and is not
misrepresented as physical evidence.
