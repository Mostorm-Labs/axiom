# GT-G4-4 — Multi-Pointer Input & Gesture Arbitration

This package executes the two Notion authorities for G4.4 from the G4 functional
integration baseline. It is a normalized input/session substrate, not a new
semantic document model. Pointer identity, gesture claims, contact geometry,
preview state, and viewport state remain derived runtime state.

Work packages are ordered G4.4-01 through G4.4-10. The physical checkpoint is
blocking for a full Gate PASS; synthetic replay is not a substitute for a real
pen plus multitouch device.
