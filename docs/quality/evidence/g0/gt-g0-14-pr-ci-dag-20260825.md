## 1. 本轮边界

本任务建立 PR 层的唯一验证链：`schema → protocol + semantic bootstrap → selected platform → aggregate`。
它没有进入 nightly/release wiring，没有实现产品 Semantic Kernel，也没有生成 G0 最终 Gate Report。

`semantic bootstrap` 复用 POC-01 host-core 的 Operation、replay、digest 和 scene projection 测试，只是
G0 CI 的 trusted-root seed。结构化摘要明确写有 `NOT_G1_SEMANTIC_ACCEPTANCE`、
`NO_PRODUCT_SEMANTIC_KERNEL` 和 `NO_60_CASE_SEMANTIC_CORPUS`，因此不能被当作 G1 晋级证据。
