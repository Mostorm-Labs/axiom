# FC05 连线预览与折线布局跟进

用户在 2026-10-25 明确要求：拖动时保持真实连接线；无遮挡时将折线中段放在两端之间；
点击连接点生成同类型对象时，能够水平或垂直直连就不增加折点。
本次调整共享 Runtime/Scene/Render，Windows/Web 继续使用同一实现。

## 原因与修复

1. 旧作业即使处理简单场景，也固定在端点解析和障碍物收集后让出执行机会。
   预览每次 pointer 更新会使旧作业失效，所以连续移动常常一直显示 Pending 诊断弦。
   现在简单路线在同一有限 quantum 内完成认证，预览缓存当前输入的终态结果。
2. 搜索图之前只有出线点、障碍边缘和域边缘，没有中线偏好。
   现在先尝试轴向直连，再尝试平行端口的中线折线和 L 形候选；每段都必须通过同一
   膨胀障碍物检查。候选被挡后继续原有有界 A*，不牺牲避障来强行居中。
   一般搜索、候选尝试共用原有累计工作预算；取消及输入代次失效规则保留。
3. 点击命中连接点圆圈的位置并不一定等于真实语义端口。零长度 Down 尚无有效的
   preview record，因此新对象定位现在单独解析语义端口，并校正垂直于出线方向的坐标。
   保留同类型生成、相对侧端口和 Connector + 对象一次原子 History。
4. 按本次用户展示要求，Pending 保留原线型和颜色，终态无路由/超预算仍用橙色虚线
   诊断。Pending 状态不伪装成 Ready，也不承诺尚未完成的避障检查已经通过。
   原先关于 Pending 橙色虚线的展示说明由本次用户要求替代，旧证据不改写。

派生算法 revision 为 2；没有修改 canonical ConnectorContent、schema 或 SDK locks。
