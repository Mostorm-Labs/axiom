## Design preflight

Exact attempts currently stop after 64 calls to a 32-knot checkpoint, even when
their CPU time is below the existing time allowance. The caller-supplied budget
remains the authority for every prepare invocation. Raise only the private
default work ceiling; explicit small limits still yield and the existing time
check still bounds admission between units. Runtime continues to own one frame
opportunity; provider present and receipt behavior are unchanged.

Prepared geometry is derived from an immutable scene/source stamp and lives in
Render, shared by tile jobs. The resource owner must account for its lifetime,
eviction and denial, including in-flight users. Local selection uses conservative
finite support and preserves original contour pairing. No unresolved semantic
decisions, authority conflict or new consumer API are introduced.
